# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。正常本地启动在数秒内完成。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功。

## 作答描述与存档

从首页选择一个学习者，查看知识点作答与尝试历史的图表与明细，点击一条记录，使用“查看原始记录”核对字段。输入会议名称并保存，然后改变所选范围；点击左侧刚保存的记录核对先前材料仍能打开，最后导出当前记录。

## 掌握判断与练习建议

点击“查看掌握判断与建议”，在知识点表中核对后验均值、80% 可信区间和四种判断标签；点击任意一行，在“记录与依据”中查看该知识点引用的每次作答、权重与不确定性。右侧“下一份练习建议”说明目标知识点、建议题目、三分类预测、证据依据、未选中候选的原因和剩余不确定性。

在左侧“教学策略”中修改截止日期、先修关系或勾选排除题目，建议会即时重算并显示变化原因；这些调整只属于本次查询，不会改动数据集。点击“恢复数据集默认策略”可还原。发布给学生的建议通过“发布当前建议”冻结，之后导入新数据或修改策略都不影响已发布内容，可在“已发布学习建议”中随时重新打开核对。

## 历史预判检验

选择“整名学生留出（新学生视角）”或“已知学生的后续表现”后运行回测。报告首先给出泄漏检查（违规必须为 0），再并列展示本模型与全体率基线的 Brier、对数损失、命中率，以及冷启动子集和按学生拆分。若本模型未优于基线，页面会直接提示，不能把模型标签当作既定结论。

整段交互通常需要1至2分钟，不依赖远程请求。`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。
